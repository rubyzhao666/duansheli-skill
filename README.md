## 💡 一句话介绍

> **大模型擅长"加法"，断舍离教它"减法"。**  
> 输入长文本 → 自动精简 + 透明对比报告 → 告诉你删了什么、为什么删。

## ✨ 核心亮点

| 能力 | 说明 |
|:---|:---|
| 🗑️ **智能删减** | 按优先级删除：套话 → 重复表达 → 无关例证 → 弱支撑 |
| 📋 **透明报告** | 每条删减都展示原文片段 + 删减原因，有据可查 |
| 🎯 **精准压缩** | 指定目标字数和保留要点数，一键输出 |
| 🔒 **只删不增** | 不添加新信息，不改写核心观点，不曲解原意 |

## 🎬 效果演示

### 使用前 vs 使用后

```
📊 原文：3,245 字（充满套话、重复、铺垫）
        ↓
   /断舍离 800 3
        ↓
📊 精简版：798 字（节省 75%）✨
   + 对比报告（10 条删减记录）
```

### 输出示例

**精简版**（保留核心观点与逻辑链）：

> 本季度 MAU 增长 44.5% 至 18,563，DAU 增长 55.8% 至 5,127。多Agent协作框架 v2.0 上线后任务完成率从 71.2% 提升至 78.6%。工具生态扩展至 67 个。Q1 营收 186.7 万元，环比 +62.3%。签约 3 家企业客户。

**对比报告**：

| # | 删减内容 | 删减原因 |
|---|---------|---------|
| 1 | "众所周知，随着人工智能技术的飞速发展..." | 套话开头，无信息量 |
| 2 | "这一机制的引入使得不同的Agent之间可以实现高效..." | 重复表达，前文已说明 |
| 3 | "在推进过程中我们也遇到了一些挑战和困难..." | 客套废话 |

## 🧠 处理流程

断舍离不是简单截断，而是遵循三原则的智能精简：

- **断（不写废话）** — 划掉看似重要实则多余的水分
- **舍（删掉冗余）** — 砍掉重复表达、同义堆砌、无效铺垫
- **离（提炼本真）** — 只保留读者真正需要的观点、事实、行动项

```
输入长文本
    ↓
① 理解原文 → 识别核心信息 & 冗余内容
    ↓
② 做减法 → 套话 > 重复 > 无关 > 弱支撑（按优先级）
    ↓
③ 输出精简版（保留语气风格与逻辑链）
    ↓
④ 生成对比报告（每条删减 + 原因）
    ↓
⑤ 总结建议（写作改进方向）
```

## 🔒 边界规则

1. **只删不减质** — 不改变核心观点、数据、结论
2. **不添加新信息** — 不写入原文没有的内容
3. **尊重专业术语** — 不为缩短而删必要词汇
4. **对比必须透明** — 每条删减必须有明确原因
5. **已精炼则肯定** — 若原文质量高，少删并给出正面评价
